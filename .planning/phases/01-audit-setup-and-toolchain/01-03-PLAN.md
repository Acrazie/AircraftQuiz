    ### Critical Cross-Layer Discrepancies

    For each gap, record: what Layer A says vs what Layer B says, and why this is a security concern.

    #### GAP-01: Symfony Profiler Exposed Without IP Restriction
    - Nginx: /_profiler routed to backend:9000 with no allow/deny guard
    - Symfony: dev firewall grants open access (security: false)
    - Risk: If APP_DEBUG=true in production, exposes full stack traces, environment variables, and session data
    - Severity estimate: CRITICAL if APP_DEBUG=true; HIGH if APP_DEBUG=false (still route exposure)
    - Phase that formally scores this: Phase 4

    #### GAP-02: Content-Security-Policy Header Absent
    - security_headers.conf: No CSP header
    - Impact: XSS attacks have no policy barrier; localStorage JWT token theft is unmitigated by headers
    - Severity estimate: HIGH (amplifies JWT storage risk documented in CONCERNS.md)
    - Phase that formally scores this: Phase 4

    #### GAP-03: HSTS Header Absent
    - security_headers.conf: No Strict-Transport-Security header
    - Nginx: Forces HTTPS redirect but does not pin HTTPS in browser
    - Impact: Users can be downgraded to HTTP on first connection (before redirect)
    - Severity estimate: MEDIUM
    - Phase that formally scores this: Phase 4

    #### GAP-04: /api/questions and Other Non-Auth API Paths Have No Nginx Rate Limiting
    - Nginx: Rate limiting only on /api/login_check, /api/token/refresh, /api/register, /api/auth/google
    - /api/questions, /api/scores, /api/profile, /api/leaderboard: No rate limiting
    - Impact: Database hammering, scraping, DoS on unauthenticated question endpoint
    - Severity estimate: HIGH for /api/questions (public, no auth required)
    - Phase that formally scores this: Phase 4

    #### GAP-05: No React Router Catch-All Route
    - App.jsx: No <Route path="*"> defined
    - Impact: Unknown paths render blank or throw React Router error (unconfirmed — verify in Phase 5)
    - Severity estimate: LOW (UX issue, not security)
    - Phase that formally scores this: Phase 5

    #### GAP-06: No React Router Auth Guards on Protected Pages
    - App.jsx: /profile, /aircraft-quiz, /ranking, /quizzes have no PrivateRoute wrapper
    - React Router layer: All routes are open client-side
    - Note: API is properly protected by Symfony JWT firewall; this is a UX concern (user sees protected UI before auth check)
    - Severity estimate: MEDIUM (UX — user navigates to protected page, API fails, experience is broken)
    - Phase that formally scores this: Phase 5
